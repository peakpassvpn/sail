pub struct TcpTable { /* private fields */ }

Shard-local passive TCP table. Receive memory is reserved before its window is advertised, and every externally held capability is generation checked.

pub fn connect( &mut self, local: SocketAddr, remote: SocketAddr, ) -> Result<(TcpFlowToken, TcpIngress), TcpTableError>

Opens a connection from local to remote (RFC 9293 3.10.1) and returns its token with the SYN to send. Port 0 in local picks a free ephemeral port. The connection reports TcpEvent::Connected once the handshake completes, or TcpEvent::Closed when it is refused or its SYN is never answered.

§Errors

Returns TcpTableError::InvalidAddress for endpoints that cannot carry a unicast flow, TcpTableError::AddressInUse when the four-tuple is live or in TIME-WAIT, or a budget error when the flow cannot be charged.
