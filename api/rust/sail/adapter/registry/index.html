Module registry 

Source
Expand description

What turns a configured inbound or outbound into a handler.

Every protocol registers a factory under its protocol name, and the managers look the name up instead of knowing each protocol themselves. Which factories exist is decided in one place, crate::include, so that adding a protocol touches that list and the protocol’s own directory and nothing else.
