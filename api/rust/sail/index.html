Reusable proxy runtime for clients, servers and relays.

Start with StartOptions and start. Portable proxy behavior lives in config, while runtime describes host capabilities and resource budgets. A running instance is identified by RuntimeId; hosts can reload, shutdown or report network_changed events for that instance.
