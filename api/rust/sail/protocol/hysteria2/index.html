Module hysteria2

Hysteria2: TCP and UDP proxied over QUIC, authenticated by an HTTP/3 request, with Brutal congestion control and optional Salamander obfuscation.

See https://v2.hysteria.network/docs/developers/Protocol/.

Modules§

inbound
The Hysteria2 inbound: an HTTP/3 server on the inbound’s UDP socket that turns authenticated connections into proxy connections.
outbound
The Hysteria2 outbound: TCP as QUIC streams and UDP as QUIC datagrams over one authenticated connection to the server.
