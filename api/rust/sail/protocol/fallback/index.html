Module fallback 

Source
Expand description

Fallback for the inbounds that authenticate in their first bytes, Trojan and VLESS, as sing-box’s trojan inbound has it: a connection that fails to authenticate is relayed to a web server, starting with the bytes read of it so far, so that an active prober meets that server rather than a connection that closes on it.

Constants§

HEADER_TIMEOUT
How long a peer that has sent less than a header is waited for before it is handed to the fallback, as Xray does: a prober that sends a few bytes and waits must get the web server’s answer, not a silence that only a proxy would keep. Only applies with a fallback; without one the inbound’s handshake deadline bounds the wait as before.
