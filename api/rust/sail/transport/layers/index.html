sail::transport

Module layers 

Source
Expand description

The blocks a protocol can be carried over – tls, transport, multiplex – its dial fields and detour, and how they become layers around it.

In a configuration they are fields of the protocol’s own entry, as in sing-box. Inside, an outbound with layers is a chain of handlers, [tls, ws, vless], and one with a detour is a chain of that and the outbound it detours through; chains are not something a configuration names.
