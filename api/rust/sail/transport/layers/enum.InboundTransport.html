Enum InboundTransport 

Source 
pub enum InboundTransport {
    Ws {
        path: String,
        forwarded_header: Option<String>,
        max_early_data: usize,
        early_data_header_name: Option<String>,
    },
    HttpUpgrade {
        host: Option<String>,
        path: String,
        headers: HashMap<String, String>,
    },
    Grpc {
        service_name: String,
        idle_timeout: Option<Duration>,
        ping_timeout: Option<Duration>,
    },
    Http(IgnoredAny),
    Quic {},
}

Variants§

§

Ws

Fields

§path: String
§forwarded_header: Option<String>

The header a trusted reverse proxy in front puts the client’s address in, such as X-Forwarded-For. Unset, no header is believed: anyone can send one.

§max_early_data: usize

The most early data a client may send in its upgrade request.

§early_data_header_name: Option<String>

The header it comes in; unset, it comes in the path.

§

HttpUpgrade

Fields

§host: Option<String>

The Host a request must carry; unset, any.

§path: String
§headers: HashMap<String, String>

Added to the response.
