Module grpc 

Source
Expand description

The gRPC transport, “gun”, as Xray and sing-box speak it: a stream is one HTTP/2 POST to /<service_name>/Tun, content-type: application/grpc, its bytes gRPC messages each way. See gun.

The inbound serves every call a connection carries, as many as the client multiplexes onto it. The outbound multiplexes likewise: it keeps a pool of connections to its server, dialled through the layers under it, and makes each stream a call on one of them; see outbound.
