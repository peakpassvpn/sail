Module gun 

Source
Expand description

“gun”, the gRPC Xray and sing-box carry a stream over: one call to /<service_name>/Tun, each way a stream of gRPC messages, each message a protobuf Hunk { bytes data = 1; } holding the next bytes.

A gRPC message is a flag byte (compressed or not), a big-endian u32 length, and that many bytes. Hunk is a single length-delimited field, tag 0x0a. Nothing needs a protobuf library for that, and a message is decoded as it arrives, never held whole.
