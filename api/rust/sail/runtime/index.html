Modules§

options
Tuning an instance runs with: buffer and queue sizes, internal timeouts and limits. They are not part of a configuration – what a user writes does not depend on them – but chosen by whoever starts the instance: a preset for the device (--profile), and single values on top of it (--set relay.buffer_size=32).
platform
What only the host can do for an instance: the embedding app, the FFI layer, or nothing at all for a command-line instance.
