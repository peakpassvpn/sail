## A client on a TUN

Every connection of the device through a TUN: DNS over HTTPS through the proxy, the LAN's names by the system's resolver, a selector over a URL test of a REALITY and a Hysteria2 server, and private addresses direct. Everything in it is sing-box's.

## A REALITY server with limits per user

## Groups from a subscription

sail's `outbound_providers`: a subscription downloaded every 12 hours, its outbounds joining a selector and, filtered by name, a URL test that falls back to direct while none is left.

`providers.json`

```json
{
  "$schema": "https://peakpassvpn.github.io/sail/schema.json",
  "outbound_providers": [
    {
      "type": "remote",
      "tag": "subscription",
      "url": "https://provider.example.com/sub.yaml",
      "update_interval": "12h",
      "download_detour": "direct"
    }
  ],
  "outbounds": [
    {
      "type": "selector",
      "tag": "proxy",
      "outbounds": ["fastest"],
      "providers": "subscription"
    },
    {
      "type": "urltest",
      "tag": "fastest",
      "providers": "subscription",
      "filter": "(?i)hong kong|singapore",
      "exclude_filter": "(?i)expire|traffic",
      "empty_fallback": "direct"
    },
    { "type": "direct", "tag": "direct" }
  ],
  "route": { "final": "proxy" }
}
```
