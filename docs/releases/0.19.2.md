## sail 0.19.2 (pre-release)

A patch release on top of 0.19.1: two security fixes and one fix,
nothing else. There are no breaking changes; configuration, the C ABI and the
Swift and Kotlin APIs are as in 0.19.1.

Documentation: https://peakpassvpn.github.io/sail/

### Security

- **A TLS server, or anyone answering as one, could make a client using
  the `firefox` TLS fingerprint exhaust memory with a compressed
  certificate.** Rule-set files in MRS format were affected the same
  way. (RUSTSEC-2026-0344, in the `ruzstd` crate, now 0.9.1.)

  Affected releases: 0.15.0 to 0.19.1. Update if you use the `firefox`
  fingerprint or MRS rule-sets from a source you do not control.
- **A TUIC inbound read stream data before authenticating the client,**
  letting unauthenticated clients make the server hold memory. Only
  servers with a TUIC inbound are affected; clients are not.

  Affected releases: 0.15.0 to 0.19.1. Update if you run a TUIC inbound.

### Fixed

- **A connection's two directions take turns.** On a connection carrying
  both directions at once, one direction could wait until the other
  finished when the relay was CPU-bound.
