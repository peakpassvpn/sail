## sail 0.22.0 (pre-release)

Documentation: https://peakpassvpn.github.io/sail/

### Fixed

- **The host's network-changed call (`network_changed` in the C ABI, and
  the Swift and Kotlin calls over it) returns once the change is
  handled:** the old network's connections and TUN flows are closed by
  then, so a host that goes on to use the new network no longer races
  them. The call waits 10 s at most, and logs a warning if the change was
  not handled by then: a host calls it on a thread that may block, never
  the main one.
