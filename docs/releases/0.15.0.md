## sail 0.15.0 (pre-release)

The first release of sail, a pre-release: configuration fields, the C ABI
and the Swift and Kotlin APIs may still change before 1.0.

sail began as a fork of [leaf](https://github.com/eycorsican/leaf) by
eycorsican and is developed on its own: it does not track leaf, and its
configuration, FFI, TCP/IP stack and TLS stack are its own. It runs
sing-box JSON, Clash/Mihomo YAML and Surge configurations as they are.

Documentation: https://peakpassvpn.github.io/sail/

The Linux binaries are static (musl). Their archives carry a systemd unit
and installer (`systemd/`, see its README): nothing is enabled or started
by installing.

### Windows: Wintun

The TUN inbound on Windows uses [Wintun](https://www.wintun.net/). Its
`wintun.dll` (0.14.1, amd64) is in the zip beside `sail.exe`, unmodified
from wintun.net and checked against its published hash, under its own
license, `wintun-LICENSE.txt` in the zip. sail uses it only through the API
of `wintun.h`, as that license allows for software distributed with it.

### Not signed

Nothing here is code-signed or notarized yet. macOS asks before the first
run: allow it in System Settings, Privacy & Security, or run
`xattr -d com.apple.quarantine sail`. Windows SmartScreen may warn as well.
Every file has a build provenance attestation instead:

    gh attestation verify sail-0.15.0-x86_64-unknown-linux-musl.tar.gz -R peakpassvpn/sail

### Swift

Add the package by its URL; the tag's `Package.swift` fetches
`SailC.xcframework.zip` from this release and checks it by its checksum:

```swift
.package(url: "https://github.com/peakpassvpn/sail", exact: "0.15.0")
// and depend on the product "Sail"
```

### Android

The AAR is not on a Maven repository: put it in your app, with the two
libraries it needs, which it does not carry.

```kotlin
dependencies {
    implementation(files("libs/sail-0.15.0.aar"))
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-core:1.10.2")
    implementation("org.jetbrains.kotlinx:kotlinx-serialization-json:1.9.0")
}
```

Its R8 rules come with it. Matching rules by app needs API 29 or later.
