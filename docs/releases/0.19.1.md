## sail 0.19.1 (pre-release)

A patch release on top of 0.19.0: one security fix, nothing else. There
are no breaking changes; configuration, the C ABI and the Swift and
Kotlin APIs are as in 0.19.0.

Documentation: https://peakpassvpn.github.io/sail/

### Security

- **A malformed handshake sent to a ShadowTLS inbound could stop the
  process.** This applies to `sail` (sail-cli) and the router builds;
  the mobile libraries end only that connection. Only instances with a
  ShadowTLS inbound are affected: the ShadowTLS outbound is not, nor is
  any instance without that inbound.

  Affected releases: 0.15.0, 0.16.0, 0.17.0, 0.18.0, 0.18.1 and 0.19.0.
  Update if you run a ShadowTLS inbound.
