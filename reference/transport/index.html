InboundMultiplex

Section titled “InboundMultiplex”

Configuration source

An inbound’s multiplex block: sing-box’s, which configures its sing-mux server, or with protocol: "amux" the amux layer below the protocol. sing-mux is served, as by sing-box, only where this block enables it: with no block, a connection to the magic destination is refused. amux takes the block’s place, so an inbound with amux serves no sing-mux.

Serde: serde (deny_unknown_fields)

Field Type Omission / flattening Source notes
enabled bool Default::default() —
serde (default)
protocol Option < String > Default::default() amux; unset, sing-mux, which sing-box’s block has no field for: its server takes smux, yamux and h2mux alike.
serde (default)
padding bool Default::default() sing-mux: refuse connections that are not padded.
serde (default)
brutal Option < InboundBrutal > Default::default() sing-box’s TCP Brutal: not supported, and an error when enabled.
serde (default)
